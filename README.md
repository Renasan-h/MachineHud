# Machine HUD

> More information for Create machines, right in your HUD.

Machine HUD is a Minecraft mod that expands the information available from
Create's Engineer's Goggles.

Equip the **Machine HUD Goggles**, look at a Create kinetic machine, and
Machine HUD displays detailed information about the machine and its kinetic network.

Currently developed for **Minecraft 1.21.1 + NeoForge**.

---

## Features

Machine HUD can display information about the machine you are looking at,
including:

### Machine Information

- **Speed**
  - Current rotation speed in RPM.

- **Stress Impact**
  - Stress impact per RPM (`SU/RPM`).

- **Stress**
  - Stress generated by the selected machine.

- **Status**
  - Current kinetic state of the machine.

- **Theoretical Speed**
  - Theoretical rotation speed of the machine.

- **Position**
  - Block coordinates of the selected machine.

### Network Information

- **Network Stress**
  - Total stress used by the kinetic network.

- **Network Capacity**
  - Total stress capacity available to the network.

- **Network Usage**
  - Percentage of the network capacity currently being used.

- **Network Size**
  - Size of the connected kinetic network.

- **Network Status**
  - Current state of the kinetic network.

## HUD

When looking at a supported Create machine, information is displayed in the
top-left corner of the screen.

![Machine HUD](https://github.com/user-attachments/assets/8481c7b2-b94f-45ba-8ae0-462ca4af3bd9)

The HUD separates individual machine information from information about the
entire connected kinetic network.

## Configuration

The displayed information can be customized from:

**Mods → Machine HUD → Config**

![Machine HUD Config](https://github.com/user-attachments/assets/2be5ed6a-2c28-424d-869b-09d758905983)

Individual HUD entries can be enabled or disabled from the configuration screen.

---

## Keybind

The default HUD toggle key is:

**`End`**

Press it to show or hide Machine HUD.

The key can be changed from Minecraft's normal Controls menu.

## Installation

1. Install Minecraft **1.21.1**.
2. Install **NeoForge**.
3. Install **Create** and its required dependencies.
4. Download Machine HUD.
5. Place the `.jar` file into your Minecraft `mods` directory.
6. Start Minecraft.

---

## Current Status

Machine HUD is currently under development.

The initial focus is providing detailed kinetic information for **Create**.

Support for additional machine mods may be added in the future.
